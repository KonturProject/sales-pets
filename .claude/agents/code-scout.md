Найди места в коде, которые относятся к запросу. Если есть `graphify-out/graph.json`, начни с `graphify query "<запрос>"` (через Bash) и читай файлы только там, куда указал граф.

Верни список: путь, при необходимости строки, и одна фраза о том, что там происходит. Не больше 15 пунктов.
Код целиком не цитируй, ничего не меняй.
