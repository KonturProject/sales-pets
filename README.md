# Питомцы отделов продаж

Игра для отделов продаж: шесть групп СР1, СР2, СР3, СР5, СР6, СР9, у каждой питомец. Питомец растёт от оплат и воронки, на общем экране виден рейтинг групп. Игра идёт со 2 по 22 ноября 2026.

Без игрового движка: Vite + TypeScript + DOM/SVG/CSS. Бэкенд: Google Apps Script + Google Таблица (`apps-script/`).

## Страницы

| Страница | Для кого | Что делает |
|---|---|---|
| `index.html` | все | общий экран: питомцы групп и рейтинг |
| `rg.html` | руководитель группы | вход по PIN группы, перенос аптечки и игрушки к питомцу |
| `admin.html` | администратор | вход по PIN, импорт xlsx, сотрудники, нормы и пороги, PIN-коды |

Сайт: `https://konturproject.github.io/sales-pets/`. Параметр `?demo=1` включает демонстрацию без бэкенда.

## Команды

```bash
npm install
npm run dev              # локальный сервер Vite
npm run build            # tsc --noEmit и сборка в dist/
npm test                 # unit-тесты движка, импорта, админки, Apps Script
npm run check:render     # браузерная проверка общего экрана (Playwright)
npm run check:admin      # браузерная проверка админки и страницы РГ против мок-бэкенда
npm run check:dist       # продакшен-сборка под /sales-pets/ против мок-бэкенда
npm run audit:publish    # дерево, вся история и dist/: секреты, xlsx, реальные фамилии
npm run mock-backend     # мок-бэкенд, исполняющий настоящий Code.gs
```

## Устройство

- `src/engine/` — чистый движок: из оплат, воронки и настроек считает состояние питомцев на любую дату.
- `src/data/` — снимок с бэкенда, опрос, отправка действий.
- `src/game/` — общий экран: комната, питомцы, рейтинг. `src/import/` — разбор xlsx воронки и оплат.
- `src/admin/`, `src/rg/` — админка и страница РГ.
- `apps-script/` — серверная часть и её тесты.
- `docs/superpowers/` — спецификация и план работ, `PLAN.md` — текущее состояние.

## Выпуск

Сайт публикуется GitHub Actions на GitHub Pages при каждом пуше в `master`. Адрес бэкенда подставляется в сборку из переменной репозитория `BACKEND_URL`. Пошаговая инструкция для человека (Apps Script, PIN, загрузка данных, откат): [`docs/deploy.md`](docs/deploy.md).

В репозитории нет PIN, реальных ФИО и выгрузок xlsx: перед публикацией это проверяет `npm run audit:publish`.
