# Питомцы отделов продаж

Игра для отделов продаж: шесть групп СР1, СР2, СР3, СР5, СР6, СР9, у каждой питомец. Питомец растёт от оплат и воронки, на общем экране виден рейтинг групп. Игра идёт со 2 по 22 ноября 2026.

Без игрового движка: Vite + TypeScript + DOM/SVG/CSS. Бэкенд: Google Apps Script + Google Таблица (`apps-script/`).

## Страницы

| Страница | Для кого | Что делает |
|---|---|---|
| `index.html` | все, экран ТВ | общий экран: домик из шести комнат, зал с досками «Герои дня», «Группа», «Топ-10»; прогулки, праздник на новую оплату, «итоги дня» после загрузки воронки |
| `rg.html` | руководитель группы | вход по PIN группы, перенос аптечки и игрушки к питомцу (на ТВ аптечка лечит, игрушка падает в комнату до конца дня) |
| `admin.html` | администратор | вход по PIN; «Итоги» (план/факт по группам и сотрудникам, ручные правки фактов), оплаты за день, импорт xlsx с разбором «кто что получит», сотрудники, нормы и пороги (дробные, «с даты»), выходные дни, ручные правки, PIN-коды |

Сайт: `https://konturproject.github.io/sales-pets/`. Параметр `?demo=1` включает демонстрацию без бэкенда.

## Команды

```bash
npm install
npm run dev              # локальный сервер Vite
npm run build            # tsc --noEmit и сборка в dist/
npm test                 # unit-тесты движка, импорта, админки, Apps Script
npm run check:render     # браузерная проверка общего экрана (Playwright)
npm run check:admin      # браузерная проверка админки и страницы РГ против мок-бэкенда
npm run check:dist       # продакшен-сборка под /sales-pets/ против мок-бэкенда
npm run audit:publish    # дерево, вся история и dist/: секреты, xlsx, реальные фамилии
npm run mock-backend     # мок-бэкенд, исполняющий настоящий Code.gs
```

## Устройство

- `src/engine/` — чистый движок: из оплат, воронки и настроек считает состояние питомцев на любую дату.
- `src/data/` — снимок с бэкенда, опрос, отправка действий.
- `src/game/` — общий экран (`tv/` — экран ТВ: комнаты, питомцы, зал, камера, события) и гнездо страницы РГ. `src/import/` — разбор xlsx воронки и оплат.
- `src/admin/`, `src/rg/` — админка и страница РГ.
- `apps-script/` — серверная часть и её тесты.
- `docs/superpowers/` — спецификации и планы работ, `PLAN.md` — текущее состояние.
- `tools/` — проверки, мок-бэкенд, трейлер; `tools/agent-bridge/` — мост к Codex для генерации картинок (`docs/agent-exchange.md`).

## Выпуск

Сайт публикуется GitHub Actions на GitHub Pages при каждом пуше в `master`. Открытые страницы узнают о новой сборке по `version.json`: экран ТВ перезагружается сам, админка и страница РГ показывают «Вышла новая версия — обновите страницу». Адрес бэкенда подставляется в сборку из переменной репозитория `BACKEND_URL`. Пошаговая инструкция для человека (Apps Script, PIN, загрузка данных, откат): [`docs/deploy.md`](docs/deploy.md).

В репозитории нет PIN, реальных ФИО и выгрузок xlsx: перед публикацией это проверяет `npm run audit:publish`.
