# Экран ТВ «Комнаты и зал» — дизайн (фаза А)

Дата: 2026-11-01. Статус: утверждено заказчиком в чате («Да, начинай А»). Макет: `rooms-and-walk.html` в корне (локальный, не в git; персонажи в нём — болванки).

## Зачем

Игра стартует 02.11. Нынешний экран — карточки гнёзд, на 1920×1080 рейтинги уходят за нижний край. Заказчик хочет экран как в макете: домик из шести комнат, зал с досками рейтингов, всё в одном кадре без прокрутки.

## Цели фазы А

- Сцена 1920×1080, масштабируется под окно целиком (`fit`), прокрутки нет ни на 1920×1080, ни на 1366×768.
- Мир 2800×1575: зал (стена, панели, пол, ковёр), домик 3×2 комнаты 529×446 (геометрия макета: `HOUSE {x:600,y:40}`, `GAP 6`), доски 470×780 на стенах зала слева (`x 70`) и справа (`x 2260`).
- Комната группы: стена и декор темы из макета, табличка (код, вид, `.sub` «стадия N · оплат M» / «яйцо · оплат M» / «питомец погиб», настроение словом, полоса сытости), табло (сменяет 4 цифры раз в 3,2 с), кучки с мухами, ящики аптечек и игрушек, мяч, рука РГ.
- Каждое состояние движка видно: `egg0/egg1/egg2` (картинки `assets/eggs/srN-K.svg`), питомец (размер растёт со стадией, `petScale`), надгробие, настроения `ok/bored/sad/sick/dead`, кучки, сытость, запасы.
- Питомцы ходят по своей комнате и пинают свой мяч (как в макете); яйцо покачивается на месте; надгробие стоит.
- Эмоции — SVG в пузыре (эмодзи на ТВ-браузере может не быть).
- Доски: слева «Герои дня» с фактами «кач 6/5 · длин 3/3», справа «Группа» (по очереди шесть групп) и «Топ-10» седьмым слайдом.
- Верхняя строка: «Питомцы отделов продаж · день N из 14» и «обновлено ЧЧ:ММ · воронка по ДД.ММ · оплаты по ДД.ММ».
- Камера: при работе с мышью (режим `active`) — общий план зала (видно всё, выбор группы и дня работает); на стене (`ambient`) — цикл «комнаты 25 с → герои 12 с → группа 18 с (3 слайда по 6 с)»; вкладка скрыта (`idle`) — всё стоит.

## Не цели (фаза Б и позже)

Прогулка в зал, праздник с конфетти по оплате, финальная графика из ChatGPT, админка и РГ.

## Ограничения

- Страница РГ не меняется: она использует `PetView`, `.stage` как зону сброса (R34) и `room.css`. Новый экран — отдельный вид `src/game/tv/`, `PetView` и `room.css` не трогаем.
- Контракт DOM для проверок сохраняется: шесть `[data-group]` с `data-phase/mood/stage/piles`, внутри `.sub` с «оплат N», `.flies` только при кучках, `[data-count="medkits|toys"]`, `.hand[data-item]`; блоки `[data-block="group|top|heroes"]` с `tr[data-employee]` и `.place/.name/.value`, `select[data-pick="group|day"]`, `[role="status"]`, текст «Игра ещё не запущена».
- Правила игры не меняются. Цифры табло считаются из уже имеющихся фактов.
- Слабое железо ТВ: без canvas, движение — `transform`, таймеры останавливаются в `idle`.

## Решения сборщика (мои)

- Виды питомцев — из спеки (львёнок, утёнок, цыплёнок, ягнёнок, совёнок, бегемотик), SVG-болванки макета; файлы `public/assets/pets/srN.svg` вместо PNG Kenney (страница РГ тоже получает правильные виды).
- «Топ-10» — седьмой слайд правой доски (в макете его нет).
- Камера подъезжает к каждой доске: на общем плане шрифт досок ≈16 px на экране, со стены не читается.
- Общий план в режиме `active`: на ПК удобно выбирать группу и день; ТВ уходит в цикл через 60 с без ввода (`PowerSaver`).
- Табло: питомец — «Стадия N / 15», «Оплат», «Качественных счетов», «Длинных презентаций» (воронка группы с начала игры по `groupOn` на дату строки); яйцо — «До вылупления M из 5 оплат»; надгробие — «Оплата сегодня — новое яйцо».
- Верхняя строка: до старта «старт 02.11», в выходной «выходной · день N из 14», после конца «игра окончена».
