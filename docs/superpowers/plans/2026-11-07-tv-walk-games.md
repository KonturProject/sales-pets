# ТВ: живая прогулка — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Питомцы на прогулке не замирают. Прогулка идёт раз в ~5 минут, длится ~80 с и включает четыре игры: догонялки по кругу, мяч с беготнёй, паровозик и чехарду.

**Architecture:**
- Геометрия и бюджеты игр — чистый модуль `src/game/tv/hallGames.ts` с тестами Vitest.
- Движение по пути с постоянной скоростью — `PetActor.run`.
- Сценарий — `Hall`: у него есть срок ухода домой, игра начинается, только если укладывается до этого срока; свободное время питомцы бродят по залу.
- Расписание камеры — `schedule.ts`: 4 круга «комнаты → герои → группа», потом прогулка.
- Живость прогулки проверяет `tools/check-render.mjs`: замер положений раз в 0,5 с.

**Tech Stack:** Vite + TypeScript, DOM/CSS, Vitest, Playwright (`npm run check:render`; часы Playwright, демо `?demo=1`).

**Spec:** `docs/superpowers/specs/2026-11-07-tv-walk-games-design.md`

## Global Constraints

- **Объём.** Меняется только экран ТВ (`src/game/tv/*`) и `tools/check-render.mjs`. Не трогаем `apps-script/`, движок (`src/engine/`), админку и страницу РГ. Правила игры не меняются.
- **Тексты дословно.** Облачка «кусь», «догоню!», «ту-ту!». Плашка прогулки остаётся «Прогулка · все гуляют в общем зале».
- **Зал.** Питомец в зале держится в пределах x 800…2000, ноги y 1130…1410. Исключения:
  - выход из комнаты и путь домой;
  - стоящий у края больной: точка в тех же пределах.
- **Скорости, px мира в мс.** Бег (догонялки, мяч) 0,4; паровозик 0,3; брожение `SPEED.hall` (0,2).
- **Время.** `HOME_MS` = 8_000. Цикл: 4 круга × 55 с + прогулка `WALK_MS` (сначала 80_000, окончательно — по замеру в задаче 5).
- **`prefers-reduced-motion`.** Прыжков дугой нет (`arc()` → 0), поэтому чехарда пропускается. Ходьба и бег остаются, как сейчас.
- **Один хозяин у питомца.** В каждый момент питомца двигает одна сцена.
  - Брожение идёт только у тех, кто в сцене не участвует.
  - Перехваченный питомец (жетон `PetActor.hold`/`owns`) выпадает, остальные продолжают.
  - Ни одна сцена не ждёт вечно.
- **Уборка.** Каждый созданный элемент (мяч, конфетти) лежит в `litter`. `stop()` возвращает всех по комнатам и убирает всё.
- **Файлы.** Окончания строк LF. Новых зависимостей нет. В git — только явными путями. Не коммитить `.claude/settings.json`, `rooms-and-walk.html`, `work/`, `graphify-out/2026-11-0*/`.

## Review Focus

1. **Питомца перехватили посреди игры** (вылупился, погиб, скрыли вкладку). Игра у остальных продолжается, промисы не висят, после `stop()` все дома и мяча нет. Тест: `check:render`, скрытие вкладки посреди прогулки (задача 2).
2. **Мало здоровых гуляющих.** Двое, один из них больной → здоровый один. Игры, которым нужно ≥ 2 здоровых, пропускаются, время занимает брожение. Тест: `gamesFor`/`gameMs` для n = 1 в задаче 3, сторож в `Hall` в задаче 4.
3. **Прогулку застали поздно** (`walkFor` после удержания доски, ~65 с). Игры, которые не влезают, не начинаются, и все дома до конца кадра. Тест: «поздняя прогулка» в `check:render` (задача 2) зелёная после задачи 4.
4. **Праздник посреди игры** (новая оплата). `hall.stop()` убирает мяч, все дома, праздник идёт. Тест: сценарий праздника в `check:render` (мусор = 0).
5. **Reduced motion.** Чехарды нет, ошибок нет. Тест: `gamesFor(true)` (задача 3).

### Task 3: Путь с постоянной скоростью и геометрия игр

**Files:**
- Create: `src/game/tv/hallGames.ts`, `src/game/tv/hallGames.test.ts`
- Modify: `src/game/tv/PetActor.ts`

**Interfaces:**
- Produces (`hallGames.ts`, без DOM):
  - `export interface Pt { x: number; y: number }`
  - `export const HALL = { x0: 800, x1: 2000, y0: 1130, y1: 1410 }`
  - `export const RUN = 0.4`, `export const TRAIN = 0.3`
  - `export function pathLength(points: readonly Pt[]): number`
  - `export function pointAt(points: readonly Pt[], dist: number): Pt` — точка на ломаной на расстоянии `dist` от начала, с зажимом в концы.
  - `export function loopPath(loop: readonly Pt[], from: number, dist: number): Pt[]` — по замкнутой петле от длины `from` (по модулю периметра) на `dist`.
  - `export function ringLoop(): Pt[]` — эллипс: центр 1400×1265, радиусы 520×120, ≥ 48 точек.
  - `export function trainLoop(): Pt[]` — волнистая замкнутая петля внутри `HALL`, не совпадает с кругом.
  - `export function ballSpot(from: Pt, rnd: () => number): Pt` — точка в `HALL` не ближе 350 px от `from`.
  - `export function roamPoint(rnd: () => number): Pt`
  - `export type Game = 'chase' | 'ball' | 'train' | 'leap'`
  - `export interface LeapGroup { members: number[]; start: Pt[]; hops: { who: number; to: Pt; arc: number }[] }`
  - `export function leapPlan(sizes: readonly number[], scale: number): LeapGroup[]` — пары (при нечётном одна тройка), каждая на своей дорожке по y; прыжки слева направо, пока помещаются в `HALL`.
  - `export function gameMs(game: Game, sizes: readonly number[]): number` — бюджет: длина пути / скорость + паузы сцены.
  - `export function gamesFor(reduced: boolean, rnd: () => number): Game[]` — `ball`, `train`, `leap` в случайном порядке, без `leap` при `reduced`.
- Produces (`PetActor`):
  - `run(points: readonly Pt[], speed: number, token: number): Promise<boolean>` — от текущей точки по `points` с постоянной скоростью:
    - один цикл `requestAnimationFrame`, положение через `pointAt`;
    - поворот по знаку dx отрезка, если |dx| > 3;
    - класс `walking`;
    - перехват по жетону → `false`;
    - страховочный таймер `длина / speed + 150` мс ставит в последнюю точку (скрытая вкладка);
    - больной идёт медленнее (`SICK`), как в `walk`.
  - `joy(): void` — `jump(46)` и облачко `joy` после прыжка, без `eager`.

- [ ] **Step 1: Тесты** `hallGames.test.ts`. Случайность — детерминированная последовательность (LCG).
  - `pathLength([(0,0),(3,4),(3,10)])` = 11. `pointAt` на 5 → (3,4), на −1 → начало, на 99 → конец.
  - `loopPath` с переходом через начало: длина результата = `dist` (± 1).
  - `ringLoop`: все точки в `HALL`, периметр 2212 ± 30. `trainLoop`: в `HALL`, замкнута, отличается от кольца.
  - `ballSpot`: 200 случайных вызовов, в том числе из углов `HALL`, — внутри `HALL` и ≥ 350 px. `roamPoint`: внутри `HALL`.
  - `leapPlan` для `sizes` длиной 2…6 (смесь 120 и 230, `scale` 1,55):
    - каждый индекс ровно в одной группе; тройка есть только при нечётном числе;
    - дорожки разные и внутри `HALL`;
    - все `to` внутри `HALL`;
    - после каждого прыжка соседи в группе стоят не ближе `(a + b) / 2 × scale × 0,6` по x;
    - `arc` ≥ 0,8 × высоты перепрыгиваемого (`size × scale`).
  - `gameMs`: при 6 питомцах любая игра от 6 до 16 с, `chase` — 10…16 с.
  - `gamesFor(true)` без `leap`; `gamesFor(false)` содержит три игры по одному разу.

- [ ] **Step 1: Срок и брожение.**
  - `start` запоминает `deadline = сейчас + ms − HOME_MS`.
  - Брожение (`roam`) у набора питомцев идёт, пока не выполнится условие (сцена кончилась) или не наступит срок.
  - Отрезок: `roamPoint` → `run` со скоростью `SPEED.hall`, пауза 0,5–1,5 с, иногда `emote('smile' | 'joy')`.
  - Отрезок начинается, только если ход плюс пауза кончаются до срока.
- [ ] **Step 2: Обычная прогулка (без `star`).**
  1. Выход.
  2. Встречи пар; кому не досталось пары — бродят.
  3. Визит к больному; остальные бродят. Потом больной медленно отходит к краю зала (точка внутри `HALL`) и смотрит на игры: поворачивается к центру, иногда `emote('sick')`.
  4. Укус (как сейчас); остальные бродят.
  5. Догонялки по кругу.
  6. `gamesFor(reduced, Math.random)` по очереди.
  7. Брожение до срока.

  Перед каждой игрой — проверка `сейчас + gameMs(…) ≤ deadline` и не меньше 2 здоровых. Иначе игра пропускается.
