# Админка к запуску (фаза В) — спека и план

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** админ ведёт игру каждый день без ошибок в данных: видит, что загружено, чьи оплаты не попали в рейтинг, правит уровни всего штата одной формой, сам меняет свой PIN.

**Architecture:** чистая логика — в `*Plan.ts` / `*Form.ts` / `today.ts` с тестами Vitest; вкладки только рисуют. Бэкенд не меняется: все действия уже есть в `Code.gs` (`setStaff`, `setProvisional`, `importPayments`, `changePin`). Браузерная проверка — `tools/check-admin.mjs` на моке.

**Spec (решения сборщика: заказчик в отъезде и поручил решать самому; источник — аудит 28.10 в `PLAN.md`):**

1. **Блок «Сегодня»** над вкладками: «Сегодня 03.11 · день 2 из 14 · воронка по 02.11 · оплаты из файла по 02.11 · предварительные сегодня: 4 из 6 групп». Без данных: «воронки ещё нет», «оплат из файла ещё нет». Обновляется при каждом переходе на вкладку и после каждой успешной записи.
2. **Превью импорта оплат**: строка «По группам: СР1 12 · СР2 8 · …» (уникальные счета, как считает экран) и, если есть, «Авторы не найдены в штате (N): …: их оплаты кормят питомца, но не идут в рейтинг. Проверьте ФИО во вкладке «Сотрудники»».
3. **Оплаты после полуночи**: перед записью вкладка «Оплаты» перечитывает «сегодня» сервера; если день сменился, ничего не пишет, показывает новые числа дня и «Наступило 04.11: числа за новый день, проверьте и сохраните ещё раз».
4. **Уровни и даты приёма всем сразу**: во вкладке «Сотрудники» раздел «Уровни и даты приёма» — таблица всего штата (ФИО, группа сегодня, уровень, дата приёма) и одна кнопка «Сохранить изменения (N)»; уходят только изменённые строки одним `setStaff`.
5. **Смена админ-PIN** во вкладке «PIN-коды»: два поля без `name`, 4–12 цифр, совпадают; `changePin`, затем вход новым PIN в ту же сессию. PIN нигде не остаётся (поля очищаются сразу).

**Не цели:** изменения `Code.gs`, кэш снимка (нужна переразвёртка заказчиком), общий стиль трёх страниц.

## Global Constraints

- PIN никогда не попадает в URL, репозиторий, localStorage, sessionStorage, консоль; у полей PIN нет `name`, `autocomplete="off"`.
- ФИО в тексте ошибок не цитировать; в превью админки ФИО показывать можно (страница только для админа, так уже делает импорт воронки).
- «Сегодня» — только `serverToday(snapshot)`.

## Review Focus

1. Таблица уровней на 60+ строках: ни одной лишней записи, если ничего не меняли; неверная дата в одной строке останавливает всё с номером строки, без ФИО.
2. Новый PIN совпал с PIN группы — сервер отклонит; сессия не должна выйти и потерять старый PIN.
3. Превью оплат: автор с «ё»/«е» и лишними пробелами считается найденным (как на экране).
4. Блок «Сегодня» до старта игры и после её конца.
5. Запись предварительных чисел ровно на смене дня — ни одной записи на вчерашнюю дату.
